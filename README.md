User Guide & Training Manual

Created by Brandon Trejo

Purpose:
This tool is designed to help laboratory staff learn, refresh, and practice common syringe volume and drug preparation calculations using a virtual syringe simulator. The program focuses on preparing doses, calculating remaining volume after drug administration, and reading syringe volumes. 
The simulator allows users to practice syringe-based tasks before performing procedures in the laboratory. Each training mode includes immediate feedback and review of missed questions to reinforce learning.

Training Modules:

Mode 1: Draw Up Volume (5 questions)
Users are given a target volume and must adjust the plunger position to draw up the requested amount.

Example
Draw up:
0.42 mL (or could be µL)
The user moves the plunger to the correct volume and submits their answer.


Mode 2: Single Dose (5 questions)
Users are given a syringe starting volume and a dose to administer. The user must move the plunger to where it should end up after the dose has been delivered.

Example
Starting Volume: 0.65 mL
Give Dose: 0.18 mL
Correct Final Volume: 0.47 mL
The user must move the plunger to the remaining volume after administration.

Mode 3: Three Doses from One Syringe (3 questions)
Users start with a  loaded syringe and administer three sequential doses. The task is to determine the correct syringe position after each dose.

Example
Starting Volume: 0.90 mL
Dose 1: 0.10 mL
Dose 2: 0.15 mL
Dose 3: 0.20 mL
The user submits the syringe position after each dose and then checks their selections.


Mode 4: Read Syringe Mode (5 questions)
A syringe position is displayed and the user must determine the volume shown and enter the answer. 
Answer units may be displayed in mL or µL depending on what is requested.


Review Missed Questions
At the end of each session, users may select Review Missed Questions. This will present the questions that the user got incorrect during the first session.

Recommended Training Progression: Practice with the mode that you are trying to work on the skill of. This can be Drawing up and reading volumes (mode 1 & 4) or dosing from a given volume (mode 2 & 3).
